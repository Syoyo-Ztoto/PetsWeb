# 武汉宠物友好地图网页

这是一个可直接打开的静态网页原型，用于验证“输入地址 + 半径筛选 + 宠物友好地点推荐”的核心体验。

## 如何打开

双击 `index.html`，或在浏览器中打开该文件。

## 当前实现

- 城市固定为武汉。
- 支持输入常见地址关键词：武汉天地、汉口江滩、光谷、街道口、武昌、汉阳。
- 支持 1 / 3 / 5 / 10 / 20 公里半径筛选。
- 支持按草坪/江滩、公园/绿道、商圈/商场筛选。
- 展示地点图片、距离、可信度、宠物友好状态、依据、电话和高德导航链接。
- 当前地点数据为示例数据，后续应替换为高德 POI + 自有审核数据库。
